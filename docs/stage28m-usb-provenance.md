**Remaining source-to-object gap:** package authentication, recorded exact revisions, selected source recipe, identical headers and consistent debug/disassembly are stronger evidence than a version tag. They do not prove every compiled C body came from a clean byte-identical tree. No signed working-tree source checksums, complete member compile commands/includes or independently reproducible object comparison was supplied. DWARF4 file entries contain no source content checksum. Initial current-master retrieval was only discovery support and is not substituted for the recorded builder. No SDK replacement is justified here.

## Source-backed transport findings

| Boundary | Exact source evidence | Consequence |
|---|---|---|
| Claim/refusal | TinyUSB tusb.c200–229; usbd.c1376; osal_freertos.h217–218 | Claim/release uses WAIT_FOREVER mutex. Existing archive has matching infinite take. Raw submit is not proven bounded/nonblocking |
| Copy/framing | hid_device.c113–131 | Claims first, copies into internal buffer, prefixes nonzero ID, submits. False may follow claim/memory-copy validation. Not every false is definitely unsubmitted/side-effect-free |
| Endpoint submit | usbd.c1389–1422 | Sets busy before DCD because completion can preempt before return. False clears busy/claimed; no genuine submission ID survives |
| DCD submit | Builder DCD601–628, actual object dcd_edpt_xfer0x00–0x4e | Spinlock, closed-endpoint refusal, otherwise store borrowed buffer/len and schedule. Specific closed guard is source-supported refusal, not blanket proof across concurrent close/reset/hardware failure |
| Transfer ownership | Builder DCD876–922; CFG defaults from installed tusb_option255–269 | Slave/FIFO path pushes packets from retained buffer, advances pointer, emits completion from interrupt. Default slave1/DMA0 source is supporting configuration; no actual FIFO/DMA physical behavior or stack latency measured |
| Callback route | dcd.h49–88,220–229; usbd.c622–707; hid_device.c386–418 | Event has rhport/endpoint/result/len, **no C/Q**. Task dispatch clears endpoint flags then calls class; HID reads reused internal epin buffer and exposes instance/borrowed bytes/len. No authentic event/connection lifetime identity |
| Reset/unplug | Builder DCD689–742,1038–1090; usbd.c630–640; hid_device.c218–221 | Reset clears transfer/interface state; patched suspend emits unplug. Neither source hook publishes a per-transfer/observer quiescence certificate. Reconnect is not retirement |
| Queue/context | usbd.c367–370,1294; osal_freertos.h249–262 | ISR sends via FromISR; non-ISR queue send WAIT_FOREVER. Ordinary callbacks are task-serviced, but producer/reset concurrency and queue drain barriers still require review |
| Core hooks | Existing protected USBHID.cpp331–374; existing ELF strong completion / weak failure | Shared semaphore wake ignores correlation. Adding a competing strong callback is prohibited. Blocking wrapper can report false after submission |

Minimal **future semantic surface**, not a patch: bounded claim/submit with explicit ownership outcome; submission-created Q carried through DCD transfer state and actual queued completion with epoch C; authoritative instance/endpoint/protocol binding; transfer and observer retirement/fence; exclusive producer lease; reviewed observer in existing strong/failed hooks. The event/class/DCD and core ABI/build implications require independently pinned tests/recipe before any modification. Tagging the current application slot at a tokenless callback remains invalid. No SDK or production adapter implements the mock's service.

**Provenance discovery progressed; real correlation, bounded entry, retirement, exclusivity, concurrency and full source-to-object attestation remain blockers.** Successful RAM traces cannot remove them.
