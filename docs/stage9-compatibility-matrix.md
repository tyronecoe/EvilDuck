# Stage 9 official compatibility matrix

Baseline: `d59562b7d08ff7833cbe1eddb07c32359138faac` (Stage 8). Audit only; production firmware unchanged. References retrieved 2026-10-11. Full source evidence and uncertainty analysis: [reference analysis](stage9-reference-analysis.md). Exact executed tests/diagnostics: [results](stage9-results.json), [audit observations](stage9-observations.json).

**Status is scoped, not a declaration of complete DuckyScript compatibility.** “Supported within bounds” means documented ordinary behavior with explicit firmware limits, verified on mocks. “Partial” means meaningful supported subsets and known missing behavior. “Unsupported” means no runtime implementation even if names can be declared as user symbols. “Intentional divergence” denotes documented policy. Hardware-inapplicable describes Rubber Ducky-specific storage/input architecture, not lack of ESP processing power. Physical USB/host effects remain unverified throughout.

Complexity: L = localized grammar/mapping/state change; M = multiple runtime/preflight/event paths; H = USB lifecycle/storage/concurrency or reference uncertainty. Priority P0 correctness prerequisite; P1 broadly useful next work; P2 subsequent feature/reference work; P3 optional or deferred. These are relative engineering estimates, not delivery dates or compatibility percentages.

| Syntax/interface | Implementation | Current behavior / tests / limits |
|---|---|---|
| `STOP` | duckscript/com/cli | Cancel run, text/delay/repeat and release owned reports; Stage1/4–8 cancellation tests. Canonical STOP_PAYLOAD is absent. |
| `VAR $name = "text"`, `DEFINE $name = value`, `$text` interpolation | duck_vars, script_parser, com | Explicit typed text compatibility path; known numeric/text identifiers expand to decimal/text. Unknown identifiers remain literal. Stage3 and Stage7 interpolation tests. |
| `IF atom`, `IF atom == atom`, ENDIF / END IF / ENDWHILE / END WHILE | script_parser | Restricted no-THEN legacy text truth/equality; canonical expressions require THEN. Stage4/5 compatibility tests. |
| `READ file $text`, `SAVE/APPEND file STRING text` | storage, spiffs, sd_card, com | Device-only text file commands. READ whole-file allocation/empty-error ambiguity remains; mocks do not prove production storage adapter behavior. Stage1/6 mocks. |
| `LOCALE US/DE`, `LED OFF` or `LED r g b`, `KEYCODE bytes…` | keyboard_locale, led, hid_backend, com | US/DE only; RGB LED and raw finite six-key report extensions. Stage8 byte-level tests; physical NeoPixel order/host locales unverified. |
| ATTACKMODE KEYBOARD / MSC / DISK aliases | script_parser, attackmode | EvilDuck names map to logical HID/storage booleans; canonical USB lifecycle incomplete. |
| CLI/web, script files on SPIFFS/SD, settings/autorun | cli/webserver/settings/.ino | Global execution ownership blocks concurrent live command injection. Web settings/storage/OTA callbacks are separate paths and are not established as transaction-isolated from a run. |
