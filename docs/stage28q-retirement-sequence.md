# Finite source-ordered retirement candidate

**UNRESOLVED for the real ESP32-S3.** No complete documented safe sequence was found. The tested component is a conditional native proposal derived from S01's actual IN-disable order, with explicit software fences added around it. Public-profile requests reject missing premises before any register request. Synthetic all-true premises allow tests of the bookkeeping implication only.

The model is tied to the selected endpoint IN register bits and source operations, not a replacement USB stack. It has independent raw/mask/CPU-pending/ISR-active/publication state, W1C hypotheses for completion/disabled, modeled read-only NAK/empty bits, explicit delayed acknowledgements, dedicated FIFO words, bounded queue4 and observer count. Neither masks nor W1C clear CPU pending. Requests never auto-ack; a scripted test schedule must supply effects. Reset/unplug/suspend only invalidate eligibility; no undocumented hardware clearing is modeled. DMA, FIFO metadata/control words, bus posted-write implementation and physical timing remain unmodeled.

## One bounded action per step

Stop admissions → checked model try-ownership → mask target → explicit producer/CPU handshake → request SNAK → poll acknowledgement → request EPDIS → poll disabled → request scoped flush → poll empty/flush complete → explicit W1C → renewed publisher/visibility fence → queued/active observer quiescence → final predicate → Retired.

This order is **source-supported plus conditional hypotheses**, not presented as an Espressif-authorized silicon procedure. It does not call the original blocking edpt_disable. Every step performs at most one instrumented model operation; no busy wait, WAIT_FOREVER, sleep, target lock or automatic resubmit. MaxSteps32 and Deadline100 caller time units are declared separately from unchanged Runtime/Planner limits. Equality exhausts either budget; uint32 modular elapsed assumes short gaps/nonambiguous wrap. Timeout/error/loss yields Quarantined, retained record and no reuse. Terminal polls perform no new work. Contention consumes a finite step; no lock is held across an ISR/handshake wait in the proposal.

A: controller/buffer retirement requires the scoped stop/flush/no-future-reader/visibility premises. B: publisher fence independently requires no CPU-pending/active ISR/publication and an explicit external handshake. C: observer quiescence requires no queued old event or active observer. D: new admission additionally requires final stable predicate, no sticky loss/race/ownership fault, valid identities and explicit owner request. A/B/C are separate flags; none is inferred from one cleared variable.

The original ticket and9-byte neutral fixture frame are const and retained through the entire sequence. Model publisher entrance accepts an explicitly retained original record; it never tags a callback from the current descriptor. This is a hypothetical software lease API, **not a field available in the real raw IRQ**. Only after Retired plus the complete reuse predicate may explicit admit_new publish fresh monotonic C/Q. Maximum IDs refuse without wrap, preserving old state. Equal bytes do not identify work. Already copied events keep old tickets and are rejected against new identity before any current receipt update.

Cancellation removes source eligibility but does not imply resource retirement. Only explicit management admission may follow a cancelled retired record, enabling a future fresh neutral/session synchronization; no destructor send, automatic arming or reconnect resume exists. Successful source acceptance additionally requires a correlated current full successful model receipt; retirement alone, failed/partial receipt or cancelled source never suffices. This predicate is not an implemented Runtime acknowledgement or host delivery.

## Falsifiable boundary

Q05/Q06 explore both same-bit arrival/ack orders; both are ambiguous and deny reuse. Q07/Q08/Q22/Q32 hold ISR/publisher/queue/observer work across the sequence. Q30 removes each premise; all reject. Q37 supplies no cooperative schedule and times out. Q19 demonstrates old queued identity cannot be accepted as new under the supplied publisher contract. Q20 deliberately violates no-late-source after the conditional gate using a forced old CPU-pending/origin injection; it falsifies that premise and invalidates reuse. The origin input is a model oracle/lease, not a hardware detection mechanism. If raw old IRQs remain possible after real reuse, the actual driver could still misidentify them; the public profile therefore remains closed.

P's original volatile-field port cannot faithfully implement W1C, raw/CPU interrupt causality or posted effects. Executing it against a plain copy and calling that this semantic model would be false. No broad DCD access rewrite or tagged controller is forced here; Q vendor-model coupling is BLOCKED until an authoritative accessor/ordering contract exists.
