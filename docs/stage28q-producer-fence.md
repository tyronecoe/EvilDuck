# Proposed endpoint producer-fence contract

Pinned source establishes an interrupt allocation on the CPU calling esp_intr_alloc, not the actual runtime core executing every EvilDuck task. dwc2_esp32.h's void wrappers allocate/free the shared controller interrupt; cross-core free may block in IPC. Ordinary FreeRTOS critical entry uses NO_TIMEOUT. Timeout-taking Xtensa APIs return failure and restore interrupt level, but no target try-lock or ISR/task synchronization was executed here.

Actual actors: stack/class/task submissions → dcd_edpt_xfer/spin(false) → schedule; normal DCD endpoint ISR → handle_epin_slave without a general matching task spin acquisition; bus-reset ISR separately uses spin(true); event queue → tud_task_ext/class → observer/core; open/close/stall/configuration/protocol/reset/suspend and direct/raw producers can disturb lifetime. Existing source/maps are in P and ledger S01–S09. Actual task pinning, ISR affinity relative to each producer, visibility and complete firmware producer inventory remain unverified.

The proposed coordinator alone owns the immutable originating record. Every admission/lifecycle producer must join its exclusive lease. Retirement first blocks admissions; each actor must acknowledge the epoch without holding a lock needed by a blocked actor. A bounded try-entry may return contention, never fabricated ownership. No task may wait while holding a critical section that an active ISR/publisher needs.

After masking endpoint publication, an explicit allocated-core handshake must account for CPU pending and ISR already entered. An ISR that entered earlier retains its original record through queue publication; task-side descriptor reuse cannot change that association. Queued events and current observers must remain counted. Queue-full/lost publication sets a sticky fault outside the full queue. Empty queue, endpoint mask, deinit return or a readiness bit is not this handshake. A failed/unknown fence retains quarantine and denies restart/reclamation.

Actual APIs supplying all those conditions are **not implemented**. The model represents a checked external fence_ack only for conditional testing. It is not a stand-in proof that esp_intr_disable/free drains per-endpoint old work. Direct/raw writes, shared-controller reset/flush-all, endpoint mapping/FIFO number, EP0 and CDC/MSC must be coordinated before the lease can be real. Whole-controller shutdown cannot be presumed harmless.

Source cancellation is independent of buffer and context ownership. Events already copied retain old C/Q; observer reclamation waits until ISR/publication, queue and active observer work are all fenced. Fresh neutral drain and later-session synchronization require new explicit identities after those conditions; no old equal zero frame satisfies them. No language_preview/Bridge/Runtime, K01 barrier or conservative E-capacity behavior is changed or executed by Q.
